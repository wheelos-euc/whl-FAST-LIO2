IKFoM numerical code and manifold definitions are preserved. The only toolkit
patch changes the dynamic shared measurement callback from a raw function
pointer to std::function so independent Cyber component instances can bind
their own measurement model without a process-global estimator pointer.

Adapted:
  src/IMU_Processing.hpp -> core/imu_processing.h
  src/laserMapping.cpp  -> core/fast_lio2_runtime_core.cc
                         core/include/common_lib.h (plane-score helper)

The adaptation retains upstream IMU initialization, mean gyro bias, S2 gravity,
midpoint integration, IKFoM prediction/update, tail acceleration/gyro deskew,
unweighted plane residual/Jacobian, extrinsic_est_en, convergence limits,
LiDAR-position local-map movement and voxel-gated insertion. The plane score
uses the original literal precision and positive comparison, including NaN
rejection. Map movement/voxel arithmetic and the five-point matching threshold
follow upstream. Public/internal algorithm defaults match laserMapping.cpp;
explicit sensor profiles remain overrides, not a second algorithm.
Initialization sample variances, overwritten by configured noise before
prediction in upstream, and ROS/debug I/O are omitted. Empty outputs and IMU
history are initialized deterministically.

Intentional boundary differences:
  - canonical validated sensor time replaces ROS/vendor preprocessing;
    all IMU samples <= scan end are included, including an exact endpoint;
  - a complete explicit extrinsic is required, never silently defaulted;
  - an invalid/nonfinite update is not published as valid or inserted into
    the map; state/covariance roll back to the IMU prediction;
    missing-IMU packages clear validity and report DEGRADED rather than
    relabeling the previous pose with a new scan time;
  - Cyber frame/message/export plumbing is retained. Process consumes one
    synchronized package so each scan can publish before the next update.
    IMU-only wakeups publish diagnostic counters, not repeated poses/clouds.
    The body-cloud accessor applies the extrinsic into IMU "body", as upstream.
