# WLR-720 LiDAR-to-IMU extrinsic

The user supplied the following transform for the WLR-720 used in this
mapping task. It has not been independently calibrated or verified for other
devices or configurations.

```text
p_imu = R_li * p_lidar + t_li
R_li = identity
t_li = (-0.0172, 0.0213, 0.0362) m
quaternion (x, y, z, w) = (0, 0, 0, 1)
```

The transform does not establish LiDAR/IMU clock synchronization. Verify the
sensor-time, frame and unit requirements in the
[sensor contract](../../docs/sensors/fast_lio2_sensor_contract.md) before use.
